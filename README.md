# مِران — اختبارات المسطرة المدنية

اختبار عربي يتضمن 180 سؤال اختيار متعدد في ست سلاسل، كل سلسلة 30 سؤالًا، مع شرح الإجابات وإحالات إلى المواد وصفحات الوثيقة المرجعية.

- وضع تدريب بتصحيح فوري ووضع امتحان.
- حفظ التقدم محليًا في متصفح المستخدم.
- الوثيقة المرجعية الأصلية في `source.pdf`.
- لا يتطلب خادمًا أو أدوات بناء.

المصدر: القانون رقم 58.25 المتعلق بالمسطرة المدنية، المنفذ بالظهير الشريف رقم 1.26.07، وفق الوثيقة المرفقة. الأسئلة تدريبية وليست أسئلة رسمية للمباراة.
